## Usage

### Log

#### Bash script with input

```sh
"$HOME/atari-monk/project/automation-scripts/scripts/log.sh"
```

#### Py script

args:

- positional
  - name
  - text
  - use "" for multiple words
- flags
  - blank/-s/-e

```sh
python3 "$HOME/atari-monk/project/automation-scripts/src/log.py"
```
